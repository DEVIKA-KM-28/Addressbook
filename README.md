Address Book Management System (C)

A simple Address Book Management System written in C language that allows users to store, manage, and search contact details efficiently using file handling.
This project demonstrates concepts such as structures, file handling, arrays, functions, and basic CRUD operations in C.

🚀 Features
➕ Add new contact
📋 View all contacts
🔍 Search contact by name
✏️ Edit contact details
❌ Delete contact
💾 Save contacts using file handling

🧠 Concepts Used
This project uses several important C programming concepts:
1,Structures (struct)
2.File Handling (fopen, fwrite, fread, fprintf, etc.)
3.Arrays
4.Functions
5..String handling
6.Menu-driven programs

Project Structure
AddressBook/
│
├── addressbook.c      # Main source code

⚙️ How to Compile and Run
Step 1: Compile the program
gcc addressbook.c -o addressbook
Step 2: Run the program
./addressbook
